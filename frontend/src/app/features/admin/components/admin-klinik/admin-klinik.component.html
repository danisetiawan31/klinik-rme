Panduan Pemasangan Layar TV Ruang Tunggu

1. Buka URL Publik

Buka browser Smart TV atau mini PC di URL /papan-antrian

2. Masukkan Token

Masukkan Display Token yang diperoleh dari tombol buat ulang di atas ke dalam dialog konfigurasi.

3. Realtime Otomatis

Layar TV akan otomatis terhubung ke WebSocket dan memperbarui nomor antrian secara live.
